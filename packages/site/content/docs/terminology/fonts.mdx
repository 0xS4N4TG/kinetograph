---
title: Fonts
description: Text uses fonts you register, never the fonts installed on the computer.
---

Kinetograph never reads the operating system's fonts. A font is available only after you register it, and you must do so before text uses it.

Google Fonts download once and are kept in `~/.cache/kinetograph/fonts`:

```tsx
import { loadFont } from '@remotion/google-fonts/Inter';

const { fontFamily } = loadFont('normal', { weights: ['400'] });
```

A font file in your project uses `loadFont` from `@remotion/fonts`, with the path from `staticFile`. In a `.json` scene, the `fonts` object maps family names to files.

A character a font lacks falls back only to the symbol fonts that ship with Kinetograph. Scripts such as CJK and Arabic have no bundled font, so load one that has them.

**Coming from Remotion:** the same `loadFont` calls.
**Coming from HyperFrames:** the 18 families it embeds are built in, and system names like `Arial` map to them as HyperFrames does.
