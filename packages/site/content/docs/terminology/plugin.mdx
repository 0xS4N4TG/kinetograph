---
title: Plugin
description: An npm package that adds components or effects and tells Studio and agents how to use them.
---

A plugin is an npm package with a `kinetograph` field in its `package.json`. The field can point to a `SKILL.md` for agents, a panel for Studio and a module of MCP tools.

Kinetograph finds the plugins a project uses by reading the `dependencies` of the nearest `package.json`. `npx kinetograph plugins` lists them with the path of each skill.

Studio shows a plugin as a card in the Props tab, with its icon and description. A list there also offers the plugins on the Kinetograph site that your project does not have yet.

**Coming from Remotion:** no equivalent. Remotion packages are ordinary npm packages.
**Coming from HyperFrames:** no equivalent.
