title: Terminology

---

These pages explain one word each. Where Remotion or HyperFrames has the same idea, the page gives its name, so you can find your way in from either. For how to do something, such as load a font or use `public/`, start from [Making videos](/docs/making-videos/compositions/).

## The video

- [Composition](/docs/terminology/composition/): one video, with an id, a size, a frame rate and a length.
- [Sequence](/docs/terminology/sequence/): a piece of the timeline that shows its children for a set length.
- [Frame](/docs/terminology/frame/): one picture, counted from 0, with `fps` and `durationInFrames`.
- [Resolution](/docs/terminology/resolution/): the size a video is drawn at, and `--scale`.
- [Scene](/docs/terminology/scene/): the JSON description of a frame, made of layers.

## The project

- [Entry point](/docs/terminology/entry-point/): the file you give to a command.
- [Root](/docs/terminology/root/): the component that lists the compositions.
- [Props](/docs/terminology/props/): input values for a composition.
- [HyperFrames page](/docs/terminology/hyperframes-page/): an HTML composition rendered as it is.
- [Asset lock](/docs/terminology/asset-lock/): `kinetograph.lock.json` pins remote files.

## Making output

- [Still](/docs/terminology/still/): one frame as a PNG, or a one-frame composition.
- [Render](/docs/terminology/render/): drawing every frame into a video file.
- [Concurrency](/docs/terminology/concurrency/): worker threads that draw frames at once.
- [Compositor](/docs/terminology/compositor/): the Rust GPU renderer, with no browser.
- [Determinism](/docs/terminology/determinism/): a frame depends only on the project and its number.
- [Doctor](/docs/terminology/doctor/): finds what the engine cannot draw.

## Tools and extras

- [Studio](/docs/terminology/studio/): the local editor.
- [Agent](/docs/terminology/agent/): a coding agent, in Studio or over MCP.
- [Panels](/docs/terminology/panels/): boxes in Studio for plugin fields and agent questions.
- [Plugin](/docs/terminology/plugin/): an npm package that teaches Studio and agents.
- [Component](/docs/terminology/component/): a ready-made piece on the site.
