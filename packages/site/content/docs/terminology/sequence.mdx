---
title: Sequence
description: A piece of the timeline that shows its children from one frame for a set length.
---

A sequence shows its children starting at frame `from`, for `durationInFrames` frames. Inside it, the children see their own frame 0 at the moment it starts.

```tsx
<Sequence from={30} durationInFrames={60}>
  <Title />
</Sequence>
```

This means a component does not need to know where it sits in the video. It only reads its own frame.

`Series` and `Loop` build on the same idea. `Series` plays sequences one after another. `Loop` repeats its children. Sound inside a sequence starts when the sequence does.

**Coming from Remotion:** the same `Sequence`, with `trimBefore`, `playbackRate` and `loop` as well.
**Coming from HyperFrames:** a clip, an element with `data-start` and `data-duration`. Those are in seconds, not frames.
