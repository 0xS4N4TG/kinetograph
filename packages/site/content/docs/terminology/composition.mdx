---
title: Composition
description: A video you can render, with an id, a size, a frame rate and a length.
---

A composition is one video in a project. It has an `id`, a `width` and `height`, an `fps` and a `durationInFrames`. It also has a component that draws each frame.

```tsx
<Composition id="Card" component={Card} durationInFrames={60} fps={30} width={640} height={360} />
```

One project can hold many compositions. Pick one with `--comp <id>`. Without it, the first one is used. List them with `npx kinetograph compositions <entry>`.

A `<Composition>` draws nothing itself. It only declares the video. Ids may use letters, digits, CJK characters and `-`, and each must be unique.

**Coming from Remotion:** the same name, the same props.
**Coming from HyperFrames:** the outermost element with `data-composition-id`, sized by `data-width`, `data-height` and `data-duration`.
