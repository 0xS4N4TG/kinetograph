This page makes a two-second title card. Install Kinetograph first: see [Installation](/docs/getting-started/installation/).

You can write the video as a Remotion-style TSX project or as an HTML page in the [HyperFrames](https://github.com/heygen-com/hyperframes) style. The steps are the same. Pick a tab where the two differ.

## Write the project

Make a folder and run `npm install kinetograph` in it. Then save one of these.

<Tabs items={['Remotion', 'HyperFrames']}>
  <Tab value="Remotion">

Save this as `index.tsx`:

```tsx
import React from 'react';
import { AbsoluteFill, Composition, Rect, Text, interpolate, registerRoot, useCurrentFrame } from '@kinetographdev/core';
import { loadFont } from '@remotion/google-fonts/Inter';

const { fontFamily } = loadFont('normal', { weights: ['400'] });

const Title: React.FC = () => {
  const frame = useCurrentFrame();
  const width = interpolate(frame, [0, 30], [0, 640], { extrapolateRight: 'clamp' });
  return (
    <AbsoluteFill style={{ backgroundColor: '#14171f' }}>
      <Text x={320} y={200} font={fontFamily} size={96} color="#ffffff">
        Hello, Kinetograph
      </Text>
      <Rect x={320} y={340} width={width} height={12} radius={6} fill="#f6c177" />
    </AbsoluteFill>
  );
};

registerRoot(() => (
  <Composition id="Title" component={Title} durationInFrames={60} fps={30} width={1280} height={720} />
));
```

Import the API from `@kinetographdev/core`, not from `kinetograph`. The `kinetograph` package is the CLI, so importing `registerRoot` from it fails. You do not need Remotion. An `@remotion/*` import, such as the font loader above, maps onto Kinetograph's own code.

A [composition](/docs/terminology/composition/) is one video: `Composition` sets its id, length in frames, frame rate and size. `useCurrentFrame` gives the [frame](/docs/terminology/frame/) being drawn, and the picture depends only on that number. Here the bar grows from 0 to 640 over 30 frames, then holds. The first render downloads Inter into `~/.cache/kinetograph/fonts`.

  </Tab>
  <Tab value="HyperFrames">

Save this as `index.html`:

```html
<!doctype html>
<html>
<head>
<style>
  body { margin: 0; background: #14171f; font-family: Inter; }
  #title { position: absolute; left: 320px; top: 200px; color: #fff; font-size: 96px; }
  #bar { position: absolute; left: 320px; top: 340px; height: 12px; width: 0; border-radius: 6px; background: #f6c177; }
</style>
<script src="https://cdn.jsdelivr.net/npm/gsap@3.12.5/dist/gsap.min.js"></script>
</head>
<body>
<div id="root" data-composition-id="hello" data-width="1280" data-height="720" data-duration="2">
  <div id="title">Hello, Kinetograph</div>
  <div id="bar"></div>
</div>
<script>
  const tl = gsap.timeline({ paused: true });
  tl.to('#bar', { width: 640, duration: 1, ease: 'none' });
  window.__timelines = { hello: tl };
</script>
</body>
</html>
```

The root element gives the size and the length in seconds, at 30 fps. The GSAP timeline in `window.__timelines` is paused and moved to each frame's time.

The first render downloads GSAP from the CDN and pins it in `kinetograph.lock.json`. `npx kinetograph fetch-deps index.html` does only that download. [HyperFrames projects](/docs/compat/#hyperframes-projects) lists what a page can use.

</Tabs>

## Look at the frames

<Tabs items={['Remotion', 'HyperFrames']}>
  <Tab value="Remotion">

```sh
npx kinetograph compositions index.tsx
npx kinetograph still index.tsx 15 -o out/hello-15.png
npx kinetograph strip index.tsx -n 12 -o out/hello-strip.png
```

  </Tab>
  <Tab value="HyperFrames">

```sh
npx kinetograph still index.html 15 -o out/hello-15.png
npx kinetograph strip index.html -n 12 -o out/hello-strip.png
```

  </Tab>
</Tabs>

- `compositions` lists each composition's id, size, frame rate and length.
- `still` writes one frame as a PNG.
- `strip` writes 12 evenly spaced frames on one sheet, labelled with the frame and the time.

## Check the project

```sh
npx kinetograph inspect index.tsx --frame 30
npx kinetograph lint index.tsx
npx kinetograph check index.tsx
```

- `inspect` prints each layer at a frame, with its bounds.
- `lint` reports overflowing text, layers off the canvas, overlapping text and missing fonts. It exits with 1 on errors.
- `check` finds type errors, such as a misspelled prop. Rendering does not type-check.

These commands take an HTML page as they take a TSX entry.

## Render the video

<Tabs items={['Remotion', 'HyperFrames']}>
  <Tab value="Remotion">

```sh
npx kinetograph render index.tsx -o out/hello.mp4 --draft
npx kinetograph render index.tsx -o out/hello.mp4
```

  </Tab>
  <Tab value="HyperFrames">

```sh
npx kinetograph render index.html -o out/hello-html.mp4 --draft
npx kinetograph render index.html -o out/hello-html.mp4
```

  </Tab>
</Tabs>

`--draft` renders at half size, for a quick look. Without it the video is 1280 by 720. The output is H.264 by default, in a `.mp4` or `.mov` file. `render` prints the frame count, the encoder and the time it took. Add `--json` to get one JSON object instead.
