---
title: Codex
description: Install the Kinetograph skills for OpenAI Codex CLI and connect the MCP server.
---

Install the skills with the `skills` CLI, and add the MCP server with one Codex command.

```sh
npx skills add 0xS4N4TG/kinetograph
codex mcp add kinetograph -- npx -y kinetograph mcp
```

The first command asks which agents to install the skills for. Pick Codex. `codex mcp list` shows the result.

## Config file

The same server written by hand, in `~/.codex/config.toml`:

```toml title="~/.codex/config.toml"
[mcp_servers.kinetograph]
command = "npx"
args = ["-y", "kinetograph", "mcp"]
```

[Agent skills](/docs/agents/skills/) lists what each skill does, and [Agent tools (MCP)](/docs/agents/tools/) lists the tools.
