title: Use with agents

An [agent](/docs/terminology/agent/) can't watch a video, so Kinetograph gives it two things:

- A **skill** that teaches it a loop: write, look, check, render. The agent can write a Remotion-style TSX project or an HTML page.
- An **MCP server** that runs each CLI command as a tool and returns frames as images. See [Agent tools (MCP)](/docs/agents/tools/).

Kinetograph needs no account, login or API key. Everything runs on your computer.

## Set up your agent

[Claude Code](/docs/agents/claude-code/), [Codex](/docs/agents/codex/) and [Cursor](/docs/agents/cursor/) each have the skills and the MCP server. [Agent skills](/docs/agents/skills/) lists the skills, [Studio's agent chat](/docs/agents/studio-agent/) is the chat inside Studio, and [Match a reference](/docs/agents/taste/) is the skill that works from a reel.

## The loop the skill teaches

1. **Write** a project file that calls `registerRoot`.
2. **Look.** `strip` shows twelve labelled frames at once, `still` shows one, and `onion` shows a motion path.
3. **Check** without looking at pixels. `inspect` gives each layer's position and bounds, `lint` reports overflow and missing fonts and assets, and `check` catches type errors.
4. **Fix** and go back to step 2.
5. **Render** with `render`. Use `--draft` for a half-size look first, and run `doctor` before a long render to see what it will leave out.

A prompt as short as "make a 5 second title card for X, check it with strip and lint, and render it to out/title.mp4" is enough to start this loop.
