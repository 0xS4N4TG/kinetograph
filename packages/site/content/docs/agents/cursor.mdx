---
title: Cursor
description: Install the Kinetograph skills for Cursor and connect the MCP server.
---

Install the skills with the `skills` CLI, and put the MCP server in Cursor's config.

```sh
npx skills add 0xS4N4TG/kinetograph
```

The command asks which agents to install the skills for. Pick Cursor.

## MCP server

Put this in `.cursor/mcp.json` in the project, or `~/.cursor/mcp.json` for every project:

```json title=".cursor/mcp.json"
{
  "mcpServers": {
    "kinetograph": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "kinetograph", "mcp"]
    }
  }
}
```

You need Node 22 or newer. [Agent skills](/docs/agents/skills/) lists what each skill does, and [Agent tools (MCP)](/docs/agents/tools/) lists the tools.
