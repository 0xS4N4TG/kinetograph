title: Studio
description: The local editor for a project, with a preview, a timeline, props and presets, plugins, export and a chat with your coding agent.

[Studio](/docs/terminology/studio/) is a local editor. You open a project in it, look at the preview, change props, pick a layer or a span of time and ask your coding agent to change it. The engine draws the preview frames, so what you see is what a render makes.

Studio starts a server on `http://127.0.0.1:3000` and opens a browser. An entry can also be a `.json` scene. The server rebuilds the project when a file changes, and runs until you stop it with Ctrl-C. The [CLI reference](/docs/reference/cli/#studio) lists the options.

## The window

Four [panels](/docs/terminology/panels/) float over the window:

- **Top bar:** the project file and a composition switcher on the left, the command menu in the middle, and the theme, the inspector toggle and the Export button on the right. While renders run, a progress pill opens the render queue. A badge says `offline` when the window lost the server.
- **Agent** on the left: the chat with your coding agent.
- **Preview** in the middle, with the timeline under it.
- **Inspector** on the right, with the Props, Scene and Renders tabs.

Drag the edge of a panel to resize it, and double-click to reset it.

### Command menu and shortcuts

Cmd+K (Ctrl+K elsewhere) opens a menu with every action in the window. Type to filter. `?` lists the shortcuts. The main ones are:

- Space plays or pauses. Left and Right step one frame (with Shift, 10 frames).
- L loops, and M mutes.
- V, H and Z pick the Selection, Hand (drag to pan) and Zoom tools.
- 0 fits the frame to the preview, and 1 shows it at 100%.

## The preview

A transport at the bottom has play, previous and next frame, a timecode box, mute and loop. Type seconds (`2.4`), `mm:ss` or `mm:ss.ff` into the timecode box to jump there. A **View** menu at the top right has **Layer controls**, **Safe zones** and the zoom steps.

Click a layer to select it. Shift-click adds to the selection, and dragging a box around layers selects them all.

If the composition has audio, the preview plays it. The picture follows the sound and drops frames rather than drift.

## The timeline

The timeline starts as a slim bar. The arrow at its left expands it into one row per layer. **Show details** opens every layer, where it would otherwise fold repeated components into one row.

Clips are coloured by kind. Video clips show a film strip and audio clips show their waveform. Click the ruler or a row to move the playhead. Drag to pick a span of time instead.

### Giving the agent a span of time

Drag across the ruler or an empty part of a row to pick a span. Click a clip to pick its span. Shift-click or Shift-drag extends it. Escape clears the span and the selected layers. The span shows as a chip in the agent's message box.

When you send a message with a span, the agent is told the span, the Sequences that overlap it and the layers visible in it. It gets one contact sheet of up to eight frames across the span, in place of a single frame.

## Props and presets

The Props tab draws a form from the composition's zod 4 `schema`:

- A select for an enum, a slider for a number with `min` and `max`, and a switch for a boolean.
- A colour input for `zColor()` and a text area for `zTextarea()`.
- A JSON box for anything else. With no schema, each field is inferred from its default value.

**Reset** returns every prop to the composition's defaults. Your edits are kept per project in the browser, so a reload keeps them. The Export dialog says whether it renders the edited props or the defaults.

**Presets** is a menu at the top of the tab. **Save preset** asks for a name and saves the props you see. A preset is a file at `presets/<composition id>/<name>.json` beside the entry, so you can commit it, and `--props` renders it from the command line. See [Plugins](/docs/guides/plugins/#presets).

### Plugin cards

A field that a [plugin](/docs/guides/plugins/) draws its own panel for shows as a card in place of the generated form. Clicking a card selects the layers its plugin made, and selecting such a layer opens its card. The card's menu copies the path of the plugin's `SKILL.md` and asks the agent about the plugin.

The **Plugins** list at the bottom of the tab has two parts. **In this project** is every plugin the project depends on. **Available** is the plugins on the Kinetograph site that the project does not have. A published one has **Ask the agent to add it**, and an unpublished one shows **Coming soon**. `--offline` stops Studio asking the site.

## The Scene and Renders tabs

**Scene** is the tree of layers at the playhead, with each layer's resolved fields and a button that copies a message about the layer for a coding agent. **Renders** is the queue of exports, with progress, the output file and a cancel button.

## Export

**Export** in the top bar (or Cmd+K) opens a dialog for the composition.

- **Whole video** or **Custom.** A custom range has a start and an end. Type them as seconds, `mm:ss` or `mm:ss.ff`, take them from the playhead with **Set to playhead**, or drag the handles of the trim bar.
- **Output:** a `.mp4` or `.mov` path, relative to the project's folder. The default is `out/<composition id>.mp4`.
- **Draft** renders at half size, for checking timing.

The export uses the props you edited. It joins the Renders queue, and the top bar shows its progress.

## The agent

The chat on the left talks to your coding agent over the Agent Client Protocol (ACP). Studio finds Claude Code, Codex or Gemini CLI on your computer. The command menu switches between them and restarts the chat, and `--agent <command>` names another one. Only Claude Code is tested so far.

The agent works in the folder you started Studio in. Studio asks you before it edits a file.

Each message carries the selection: the project file, the composition, and the frame or span. For each selected layer it adds the name, kind, source file and line, position, size and current look, and the plugin that draws it. Keep the picture switch on to attach a picture of the selected area, or a contact sheet for a span.

The agent also gets a Kinetograph MCP server with every `kinetograph` command, the tools of your plugins, and four tools for the open window:

- `studio_get_props` reads the props the preview shows, and `studio_set_props` sets them. The agent can try values while you watch the preview change.
- `studio_open_panel` and `studio_panel_result` let it ask you for a decision in a panel.

See [Studio's agent](/docs/guides/plugins/#studios-agent).

Studio listens on `127.0.0.1` by default, and the agent needs the token in the address Studio opens. If you set `--host` so other computers can reach Studio, the agent is off unless you pass `--allow-remote-agent`.
