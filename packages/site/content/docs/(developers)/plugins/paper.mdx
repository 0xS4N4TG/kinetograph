---
title: Paper
description: Keyword match cuts, photo cut-outs that unfold from a crumpled packet, and hand-drawn lines round a moving subject on torn paper.
---

```sh
npm install @kinetographdev/paper
```

Paper brings creases, scanned fibres and grain to a video. From them it makes keyword match cuts, photo cut-outs and hand-drawn lines on torn paper. Five paper stocks (white, newsprint, kraft, binder and cardboard) and four edge styles (torn, cut, wavy and sticker) are built in.

## Use it

```tsx
import { MatchCut, flicks } from '@kinetographdev/paper';

// a paper flick on every cut, as a sound track
flicks({ frames: 150, fps: 30, cutsPerSecond: 10 });

<MatchCut keyword="Super Bowl" preset="web" />
<MatchCut keyword="Super Bowl" preset="broadsheet" look={{ zoom: 1.2, highlight: '#ffd400' }} />
```

On your own screenshots, give each a rough box round the keyword:

```tsx
<MatchCut
  keyword="Super Bowl"
  screenshots={[{ src: 'shots/a.png', hint: [212, 1180, 388, 64] }]}
  everyNth={1}
  showKeyBox
/>
```

## Main components

| Component | What it does |
|---|---|
| `<MatchCut>` | A highlighted keyword holds still while the page under it changes several times a second. It fills its composition. |
| `<CutOut>` | A photo with its background already removed (a PNG with alpha) as a paper cut-out. |
| `<FoldOut>` | A cut-out that unfolds from a crumpled packet to a flat sheet, in stop motion. |
| `<Scrapline>` | A marker, pencil, crayon, scribble or brush line drawn round a moving subject, on torn paper. |
| `<Paper>` | The sheet itself: a tint, crumpled creases and a scan. |

Key props:

| Prop | On | What it does |
|---|---|---|
| `keyword`, `preset`, `look` | `MatchCut` | The word, a look by name (`broadsheet`, `clean`, `crumpled`, `web`) and changes to it. |
| `screenshots`, `everyNth` | `MatchCut` | Your own pages, and how often one shows between made-up pages. |
| `src`, `edge`, `stock` | `CutOut`, `FoldOut` | The picture with alpha, its edge style and its paper. |
| `delay`, `duration`, `steps` | `FoldOut` | When it starts opening, how long it takes, and its stop-motion rate. |
| `trace`, `line`, `paper` | `Scrapline` | Where the outline comes from, the line style and the paper behind it. |

The sound helpers `flick`, `flicks`, `crinkle`, `land` and `unfolds` make the paper sounds. The full lists are on the [Paper page](/plugins/paper/).

## In Studio and with an agent

Studio gets a Paper panel for `MatchCut`: a card for each look, a page layout picker, sliders for keyword size, cuts per second, push-in and grain, and a box on the preview that you drag onto the keyword. `CutOut` and `FoldOut` get a sheet view with edge and paper cards.

## Limits

- `CutOut` and `FoldOut` need a picture whose background is already removed.
- `Scrapline` traces a picture with alpha, a black and white matte video or an SVG path.
- The plugin adds no agent tools. An agent sets values in Studio, checks the preview, then writes the look into your code or a preset.
