```sh
npx kinetograph doctor src/index.tsx --range 0..120
```

```sh
npx kinetograph doctor html/index.html --range 0..120
```

`doctor` goes through every frame of a project without the GPU. It reports each element and property the engine cannot draw, and the frames where it happens.

Unsupported content is drawn without, or approximated, and a warning names it. Nothing falls back to a browser. This is decided frame by frame.

To make it an error, add `--strict` to `render`, `still` or `strip`. The first frame with unsupported content stops the command with `UNSUPPORTED_CONTENT`, and no output file is left behind.

Run `doctor` with no entry to see the Node version, the platform, whether the addon loaded and which renderer is in use.
