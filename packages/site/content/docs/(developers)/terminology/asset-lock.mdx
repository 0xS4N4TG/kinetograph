---
title: Asset lock
description: kinetograph.lock.json, which pins the remote files a page loads so renders stay the same and offline.
---

An HTML page can load scripts, modules, pictures, media and fonts from the web. Kinetograph downloads them before frame 0, so no frame waits on the network.

`kinetograph.lock.json` sits beside the entry point. It records the SHA-256 and size of each file at its first download. Every later run checks the cache against it. A file that changed stops the command and names the URL. Commit the file.

```sh
npx kinetograph fetch-deps html/index.html
```

`fetch-deps` does the download on its own, for CI or a warm cache. `--update` downloads again and accepts changed files. `--offline` on other commands never downloads.

Only a few hosts are allowed by default, such as `cdn.jsdelivr.net` and `unpkg.com`. `--allow-host` adds one.

**Coming from HyperFrames:** your page keeps its CDN links. Kinetograph pins the files the first time you render.
**Coming from Remotion:** no equivalent.
