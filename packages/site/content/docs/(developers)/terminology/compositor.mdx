---
title: Compositor
description: The Rust program that draws a scene on the GPU, with no browser involved.
---

The compositor is the part of Kinetograph that makes pixels. It is written in Rust and loaded into Node as a native addon, `@kinetographdev/native`.

Node runs your project and turns each frame into a scene. The compositor draws that scene on the GPU with wgpu. Skia draws vector shapes, text and Canvas 2D. Layers Skia cannot draw, such as 3D and GLSL shaders, go through the wgpu path, and Skia composites them. Finished frames go to FFmpeg to be encoded.

No browser is used anywhere, not even for canvas or WebGL. A CSS or SVG feature is either drawn by Kinetograph's own code or reported as unsupported.

Run `npx kinetograph doctor` with no entry to see which renderer your install uses.

**Coming from Remotion:** it takes the place of headless Chrome.
