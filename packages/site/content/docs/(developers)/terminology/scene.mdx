---
title: Scene
description: The JSON description of one frame, made of layers, that the engine draws.
---

A scene is a JSON object with a size, a frame rate, a length and a list of layers. The engine draws a scene the same way every time.

A layer is one item in it: a shape, text, an image, a group, a video and so on. Layers are listed bottom first. Each has an `id`, a `transform`, an `opacity`, `effects` and more.

```json
{ "id": "dot", "type": "shape",
  "shape": { "kind": "ellipse", "width": 40, "height": 40 },
  "fill": "#7aa2f7", "transform": { "x": 500, "y": 280 } }
```

You can write a scene by hand and pass the `.json` file to any command. A TSX project makes a scene for each frame. Its native elements, such as `Rect`, `Text` and `Layer`, become layers.

**Coming from Remotion:** no equivalent. Remotion draws the browser's DOM.
**Coming from HyperFrames:** no equivalent. The page's HTML is drawn by Kinetograph's own DOM engine into layers.
