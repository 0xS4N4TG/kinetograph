---
title: Sequence
description: A piece of the timeline that shows its children from one frame for a set length.
---

A sequence shows its children from a start point for a set length. Inside it, the children see their own frame 0 at the moment it starts. A component then does not need to know where it sits in the video.

<IconTabs>
  <Tab label="Remotion" icon="remotion">

```tsx
<Sequence from={30} durationInFrames={60}>
  <Title />
</Sequence>
```

  </Tab>
  <Tab label="HyperFrames" icon="hyperframes">

```html
<div id="title" data-start="1" data-duration="2">...</div>
```

  </Tab>
</IconTabs>

In HyperFrames a sequence is a clip. Its times are in seconds, so 1 second in and 2 seconds long match the 30 and 60 frames.

`Series` plays sequences one after another. `Loop` repeats its children. Sound inside a sequence starts when the sequence does.
