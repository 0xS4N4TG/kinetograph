---
title: Entry point
description: The file you give to a command, which loads the project.
---

The entry point is the file a command opens. It can be one of three things.

- A TSX, TS, JSX or JS file that calls `registerRoot`.
- A `.json` scene file.
- An HTML page, or the folder that holds its `index.html`.

<Tabs items={['Remotion', 'HyperFrames']}>
  <Tab value="Remotion">

```sh
npx kinetograph render src/index.tsx
```

  </Tab>
  <Tab value="HyperFrames">

```sh
npx kinetograph render html/index.html
```

  </Tab>
</Tabs>

A file that only exports a component is not an entry point. The project needs a `registerRoot` call, or the command stops and says so.

`kinetograph.lock.json` and the `presets/` folder are kept beside the entry point. `npx kinetograph init` makes `src/index.tsx`, or `html/index.html` with `--html`.
