---
title: Packages
description: The published Kinetograph packages and when you would install each one.
---

Most people install only [`kinetograph`](/docs/packages/kinetograph/), which pulls in what it needs. The rest are for building on the engine or for adding a library or plugin.

| Package | What it is |
|---|---|
| [`kinetograph`](/docs/packages/kinetograph/) | The command-line tool and MCP server. Most people install only this package. |
| [`@kinetographdev/core`](/docs/packages/core/) | The authoring API a project imports: Composition, Sequence, interpolate, spring, Text, Image and more. |
| [`@kinetographdev/react`](/docs/packages/react/) | The React renderer that turns components into scene JSON. |
| [`@kinetographdev/compat`](/docs/packages/compat/) | Remotion compat mode: draws DOM elements and CSS natively, and reports what it cannot draw. |
| [`@kinetographdev/scene`](/docs/packages/scene/) | TypeScript types for scene JSON, and the effect and paint helpers. |
| [`@kinetographdev/audio`](/docs/packages/audio/) | Web Audio synthesis, mixing and loudness analysis. |
| [`@kinetographdev/native`](/docs/packages/native/) | The Rust renderer as a Node-API addon, with one package for each platform. |
| [`@kinetographdev/studio`](/docs/packages/studio/) | The Studio server and browser UI. |
| [`@kinetographdev/gsap`](/docs/packages/gsap/) | GSAP timelines that show the same frame alone or in order. |
| [`@kinetographdev/anime`](/docs/packages/anime/) | anime.js v4 timelines that show the same frame alone or in order. |
| [`@kinetographdev/motion`](/docs/packages/motion/) | Motion animations tied to the frame. |
| [`@kinetographdev/p5-brush`](/docs/packages/p5-brush/) | A p5.brush canvas that redraws from the frame number. |
| [`@kinetographdev/hexed`](/catalog/plugin-hexed/) | Roll a look onto a picture or clip from a number. |
| [`@kinetographdev/paper`](/catalog/plugin-paper/) | Paper cut-outs, match cuts and hand-drawn lines. |
| [`@kinetographdev/vj`](/catalog/plugin-vj/) | Screen and sensor looks, tracking marks and pop art. |
| [`@kinetographdev/kinetic-typography`](/catalog/plugin-kinetic-typography/) | Captions that move with the voice. |
