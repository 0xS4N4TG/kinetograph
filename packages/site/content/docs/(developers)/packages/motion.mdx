---

A library adapter. Install it when a project animates with Motion, so its animations resolve to the same state alone or in order.

```sh
npm install @kinetographdev/motion motion
```

Current version: 0.3.0.

## Exports

- `<MotionFrame>`: runs Motion's loop to the frame's time.
- `useAnimateAt`, `useMotionTime` and `useSpringAt`: animations that are functions of the frame.
