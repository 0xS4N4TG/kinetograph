A library adapter. Install it when a project draws with p5.brush.

```sh
npm install @kinetographdev/p5-brush p5.brush
```

Current version: 0.3.0.

## Exports

- `<BrushCanvas seed draw>`: reseeds the brush and redraws from the frame number.
