The types of the scene JSON that the renderer reads, and the helpers that build effects, paints and motion blur. Pure TypeScript with no dependencies. Install it to write or check scene files by hand.

```sh
npm install @kinetographdev/scene
```

Current version: 0.3.0.

## Exports

- Types of the whole scene format (`SceneJson`, `LayerJson` and more).
- Effect helpers such as `blur`, `glow` and `dropShadow`, and paint helpers such as `linearGradient`.
- The effect catalog, and the types for canvas, WebGL, WebGPU and video frames.
