The local server and browser UI behind `kinetograph studio`. `kinetograph` depends on it. Install it to start Studio from your own code.

```sh
npm install @kinetographdev/studio
```

Current version: 0.3.0.

## Exports

- `startStudio`: start the server for an entry (`entry`, `port`, `host`, `open`, `props`).
- `openerCommand`, and the protocol types and frame message coders (`/protocol`).
