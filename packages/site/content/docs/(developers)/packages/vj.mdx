A plugin. Install it for CRT, VHS, thermal and 1-bit looks, and boxes drawn on what moves.

```sh
npm install @kinetographdev/vj
```

Current version: 0.1.0.

## Exports

- `PopArt`, `Blobs`, `HalftonePoster`, `Fragments` and `Reticle`, and layer effects such as `crt`, `vhs` and `thermal`.
