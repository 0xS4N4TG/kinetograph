---

A library adapter. Install it when a Remotion-style project animates with GSAP. A HyperFrames page needs no adapter.

```sh
npm install @kinetographdev/gsap gsap
```

Current version: 0.3.0.

## Exports

- `useGsapTimeline(build)`: a paused timeline seeked to the frame.
- `<GsapTimeline build>`: the component form.
