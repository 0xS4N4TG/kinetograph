A library adapter. Install it when a project animates with anime.js.

```sh
npm install @kinetographdev/anime animejs
```

Current version: 0.3.0.

## Exports

- `useAnimeTimeline(build)`: a paused timeline seeked to the frame.
- `<AnimeTimeline build>`: the component form.
