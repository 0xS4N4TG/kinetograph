A plugin. Install it for rolled looks: a grade, a print screen, lens effects, tape damage and a camera shake.

```sh
npm install @kinetographdev/hexed
```

Current version: 0.1.0.

## Exports

- `Hexed`, `Grunge` and `TimeLayers`.
