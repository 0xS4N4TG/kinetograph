---
title: HDR video
description: Kinetograph renders SDR (BT.709) today. HDR output is not supported, and an HDR source clip is read as SDR.
---

Kinetograph renders standard dynamic range. Every video it writes is tagged BT.709 (colour matrix, primaries and transfer), with limited range. HDR output, meaning BT.2020 with a PQ or HLG transfer curve, isn't supported, and there is no flag for it.

## 10-bit is not HDR

`--pixel-format yuv420p10le` and ProRes write 10 bits per channel, but the file is still tagged BT.709 SDR. See [4K rendering](/docs/rendering/4k/) for when that is worth using.

## An HDR clip in your project

A `Video` layer can play an HDR source file. The engine reads the file's colour matrix, including BT.2020, to convert it to RGB. It ignores the HDR transfer function (PQ or HLG), so the clip is treated as SDR: expect it to look flat or dim next to how an HDR player shows it. If the look matters, grade the clip to SDR in your editor first and use that file.

An untagged clip is read as BT.709 from 720 lines up and BT.601 below. See [Assets](/docs/making-videos/assets/#videos) and [What works](/docs/compat/#video-and-audio).
