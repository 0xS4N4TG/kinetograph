---

`@remotion/effects` is Remotion's package of shader effects (`blur()`, `vignette()`, `glow()`) for canvas components. Kinetograph runs the copy in your project's `node_modules`. Install the package yourself, at the same version as `remotion`. It is covered by Remotion's licence, and a company may need a Remotion Company License to use it; Kinetograph ships none of its code.

```tsx
import { CanvasImage } from 'remotion';
import { blur } from '@remotion/effects/blur';
import { vignette } from '@remotion/effects/vignette';

<CanvasImage src={staticFile('photo.png')} effects={[blur({ radius: 12 }), vignette()]} />;
```

- `effects` works on every component Remotion gives it to, such as `<Img>`, `<CanvasImage>`, `<Gif>`, `<Video>` and the `@remotion/shapes` components. `<Video>`, `<Gif>` and the shapes also take the engine's own `effects` (`blur(8)`) in the same array.
- Each effect runs on WebGPU, WebGL 2 or 2D, whichever draws the frame first, and warns once if it falls back. `--preferred-effect-backend webgpu|webgl2|2d` tries one first.
- `kinetograph doctor <entry>` prints the installed `@remotion/effects` version and lists the effects your project imports that are approximated or not yet supported.
