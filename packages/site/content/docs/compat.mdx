title: Remotion compatibility
description: What works when you render a Remotion project with Kinetograph, what happens to things the engine can't draw, and how to check a project first.
---

Kinetograph renders Remotion projects without a browser. Your `remotion` and `@remotion/*` imports run on Kinetograph's own version of those packages, and the engine draws every frame itself.

Most projects just work. When something can't be drawn, Kinetograph tells you. To move a project, see [Migrate from Remotion](/docs/guides/migrate/). For gaps, see [Known issues](/docs/known-issues/).

## What happens to things the engine can't draw

The engine never switches to a browser. It skips the item, or draws something close, and prints a warning.

- `render`, `still` and `strip` print one line per kind of problem. Each line names the element, property, reason and frames. At most 12 lines are shown.
- A warning appears only on frames where the element is on screen. `display: none` and `visibility: hidden` elements are not checked.

### Make unsupported content an error with `--strict`

`render`, `still` and `strip` accept `--strict`. The first frame with anything unsupported stops the command with the error code `UNSUPPORTED_CONTENT` and exit code 1. The error names the frame and lists up to five items. A stopped `render` leaves no output file.

Use `--strict` in CI and for final renders. Leave it off while you work.

### Check a project before you render

- `kinetograph doctor <entry>` goes through every frame without the GPU. It lists what the engine can't draw, on which frames, and any scene a render would refuse. Run it before a long render.
- If the project imports an unsupported package such as `@remotion/three`, `doctor` lists the import and its file, and still checks the frames it can.
- `kinetograph lint` adds one `compat` warning per problem.
- `doctor` is also an MCP tool, and `still`, `strip` and `render` take `strict` there.
- With `--json`, the full list is in the result under `compat.leftOut` (`element`, `property`, `reason`, `values`, `frames`).

`bench`, `onion` and `snapshot` don't warn. The studio shows a frame's unsupported items as a warning.

## What works

Plain HTML and SVG elements can sit next to Kinetograph's own elements in one tree. You don't switch compatibility on.

### Remotion packages

- `@remotion/transitions`: all 19 presentations and `useTransitionProgress`.
- `@remotion/light-leaks`, `starburst`, `sfx`, `zod-types`, `timeline-utils`, `canvas`, `motion-blur`, `layout-utils` and `captions`.
- `@remotion/media-parser` and `@remotion/webcodecs`: partly supported.
- `@remotion/skia` and `@shopify/react-native-skia`: real Skia in an optional add-on, on the CPU. `useVideo` works without its sound.
- `@remotion/rive`: Rive's own runtime, with `stateMachineInputs`, `onLoad`, `assetLoader`, `effects` and referenced assets.

### Audio and video

- `<Audio>` and `<Video>` from `@remotion/media`.
- `@remotion/media-utils`: `getAudioData`, `useAudioData`, `useWindowedAudioData`, `getAudioDurationInSeconds`, `visualizeAudio` and `getWaveformPortion`. `visualizeAudio` follows Remotion's documented behaviour, but its numbers are not identical.
- `toneFrequency` on `<Audio>` and `<Video>`, from 0.01 to 2. It changes the pitch and keeps the length.
- `onVideoFrame` on `<Video>`, `<OffthreadVideo>` and `<Html5Video>` hands your code the frame as a canvas image source. Use `ctx.drawImage(frame, ...)` and `getImageData`. See [Video pixels](/docs/known-issues/#video-pixels).
- `<Video datamosh>` is Kinetograph's own prop. See the [Datamosh guide](/docs/guides/datamosh/).

### Canvas and WebGL

`<canvas>` with a `webgl` or `webgl2` context runs on the GPU, with no browser.

- Supported: fragment shaders, framebuffers, `gl_PointSize`, instancing, `gl_VertexID`, `blitFramebuffer`, `texSubImage2D`, depth and stencil tests, `drawBuffers`, depth textures and renderbuffers.
- Not drawn: lines and multisampled renderbuffers.
- p5.brush's standalone build draws as it does in Chrome.

### CSS and project files

- `import './index.css'` works, and local `@import`s are inlined.
- Tailwind is built with your project's own setup.
- `*.module.css` files export their scoped class names.
- `staticFile` reads `public/` next to the entry, else `public/` next to the nearest `package.json`.

### Fonts and text

- Fonts load from files, through `new FontFace(...)` with `document.fonts.add(face)`, or an `@font-face` rule.
- One file is kept per family, weight and style. For a `unicodeRange` split, the basic Latin part is used.
- A variable font with a weight range (`font-weight: 300 1000`) follows the requested weight in the DOM and on Canvas 2D.
- Kinetograph reads no system fonts, so a render looks the same on every machine.
- With no font loaded, text uses DM Sans, which ships with Kinetograph. `doctor` and the warning say so.
- A missing character (arrow, check mark, maths sign, emoji) comes from a bundled font: Noto Sans Symbols 2, Noto Sans Math or Noto Emoji. Emoji are monochrome.
- A character none of them has, such as CJK, is drawn as a box and reported. Load a font that has it.
- `-webkit-text-stroke` and `paint-order: stroke fill` work, with `text-shadow`, transforms, opacity and `background-clip: text`.

### 3D, backgrounds and filters

- `transform-style: preserve-3d` planes that cross each other intersect, as in Chrome.
- `preserve-3d` is flattened where a browser flattens it, for example on elements with `opacity` below 1, a `filter`, `clip-path`, `mask-image`, `mix-blend-mode` or a non-visible `overflow`.
- `background-repeat: space` and `round` work for gradients and pictures.
- `backdrop-filter: blur()` reads only the backdrop inside the element's border box, as Chrome does.
- `filter: blur()`, `drop-shadow()` and `backdrop-filter` take any radius. Past 532 px they are drawn 532 px wide, which is Chrome's limit.
- The same filter functions work inside an `<svg>`, next to `filter: url(#id)`.

### GSAP

GSAP (core, free plugins and `Flip`) works on the page's elements and SVG. Build a paused timeline in a layout effect and seek it to the frame, which is the pattern Remotion documents:

```tsx
const frame = useCurrentFrame();
const { fps } = useVideoConfig();
const tl = useRef<gsap.core.Timeline>(null);
useLayoutEffect(() => {
  const t = gsap.timeline({ paused: true });
  t.to(box.current, { x: 600, rotation: 45, backgroundColor: '#e0261b', duration: 1 });
  tl.current = t;
  return () => { t.kill(); };
}, []);
useLayoutEffect(() => { tl.current?.seek(frame / fps); }, [frame, fps]);
```

- You can tween transforms, `opacity`, colours, sizes, `boxShadow`, `filter`, `clipPath` and the rest of the CSS the engine draws.
- SVG: `attr` (`cx`, `r`, `d`), `strokeDashoffset`, `fill` and transforms.
- Plugins: `TextPlugin`, `SplitText`, `DrawSVGPlugin`, `MotionPathPlugin` and `CustomEase`.
- `Flip.getState(...)`, then `Flip.from(...)` on a paused timeline seeked to the frame.
- `ScrollTrigger` and `Draggable` don't apply, because a render has no scrolling or dragging.

A tween that plays by itself, such as `gsap.to(...)` in a `useEffect`, also works. Kinetograph moves GSAP's root clock with the frame.

- The CLI finds your GSAP through `import 'gsap'` or `'gsap/all'`, or at `window.gsap` for a HyperFrames page.
- A tween made at frame 30 starts at frame 30. A frame renders the same alone as in a full render, at any `--concurrency`.
- When a scene starts over, tweens already made are kept. Stop a tween in the effect's cleanup with `return () => tween.kill()`.
- A tween on the root clock gets one warning. Remotion moves it by the wall clock, and HyperFrames seeks only timelines on `window.__timelines`. For the same result everywhere, use a paused timeline.

## HyperFrames projects

`kinetograph render`, `still`, `doctor` and `studio` take a [HyperFrames](https://github.com/heygen-com/hyperframes) project as it is. Pass its `index.html`, or the directory that holds it. Nothing is rewritten, and nothing runs in a browser. For the steps, see [Migrate from HyperFrames](/docs/guides/migrate-hyperframes/).

```sh
kinetograph render my-video -o out.mp4   # downloads what the page loads from the web first, then renders offline
kinetograph render my-video -o out.mp4 --offline   # never downloads; a file that is not cached is an error
kinetograph fetch-deps my-video          # the same download on its own (CI, a warm cache); --update refreshes it
```

### Size, clips and compositions

- The root `data-composition-id` element gives the size (`data-width`, `data-height`) and length (`data-duration`, else the longest timeline or clip). The rate is 30 fps.
- An element with `data-start` shows from its start for `data-duration`. `data-start` takes seconds, or `clip-id`, `clip-id + 2`, `clip-id - 0.5`.
- A video or audio without `data-duration` lasts its file. An `<img>` with only `data-start` lasts 3 s.
- `data-hidden` removes a clip from the picture, and its audio from the mix.
- `data-composition-src` mounts the file's `<template>` into the host. Its CSS and scripts are scoped to the composition.
- `data-variable-values` and `getVariables()` work.
- The page's `html` and `body` behave as in a browser. `rem` counts the `html` font size, and a background on either fills the picture.

### Timelines and media

- Every frame, each `window.__timelines` entry is paused and seeked. A frame depends only on its number.
- `<video>` is decoded by the engine, frame-accurate. It follows `data-media-start` and `data-playback-rate` (kept to 0.1 to 10).
- `<audio>` and unmuted `<video>` are mixed, with `data-volume`, `data-fade-in` and `data-fade-out`.
- A media element in a composition whose host has `data-playback-start` is cut to the host's window. `data-hf-media-start-basis="global"` keeps a start that is already the project's.
- `data-automation` takes `rate` lanes (speed ramps) and `volume` lanes (capped at +12 dB).

### Audio effects and colour grading

- `data-fx-chain` plays all sixteen HyperFrames effects: `gain`, `peaking`, `lowshelf`, `highshelf`, `highpass`, `lowpass`, `compressor`, `limiter`, `truepeak`, `gate`, `saturate`, `bitcrush`, `pitchshift`, `delay`, `chorus`, `phaser` and `reverb`.
- It works on an element, an `<hf-audio-group>` and the master bus, with presets and `fx.*` lanes. HyperFrames' own processors run with no browser.
- A chain or lane that can't be read stops the mix with an error that names the element.
- `data-color-grading` on `<video>`, `<img>` and `<canvas>` runs HyperFrames' whole grading shader as one GPU pass. It covers `adjust`, `wheels`, `curves`, `hueCurves`, `secondaries`, `.cube` luts, `intensity`, `details`, all 18 `effects` and the `palette`.
- Your own components can use `{ type: "colorGrade", effects: { halftone: 0.9 } }`. See SCENE.md.

### Fonts

- The 18 families HyperFrames embeds are available in every weight Google serves: Inter, Montserrat, Outfit, Nunito, Oswald, League Gothic, Archivo Black, Space Mono, IBM Plex Mono, JetBrains Mono, EB Garamond, Playfair Display, Source Code Pro, Noto Sans JP, Roboto, Open Sans, Lato and Poppins.
- System names map as in HyperFrames. `Arial`, `Helvetica`, `Verdana` and `Calibri` become Inter. `Consolas`, `Menlo` and `Courier New` become JetBrains Mono. `Georgia`, `Times New Roman` and `Palatino` become EB Garamond.
- Fonts come from the cache that `fetch-deps` fills. A render never downloads a font.

### Downloads and the lock file

Nothing is downloaded while a frame is drawn. Before frame 0, commands that open a project download what the page loads from the web. `--offline` skips this, and `kinetograph fetch-deps <entry>` runs it alone.

- Allowed hosts are `cdn.jsdelivr.net`, `unpkg.com`, `cdnjs.cloudflare.com`, `esm.sh` and `cdn.skypack.dev`, over https. `--allow-host` adds one.
- This covers scripts, modules, data files a script names, remote `<video>` and `<audio>` (500 MB each, `--max-media-mb`), and pictures (50 MB each). `--url` adds a file a scan missed.
- If a file isn't cached, the command stops and names the URL and `fetch-deps`. A picture is drawn without and reported, and `--strict` fails on it.
- `kinetograph.lock.json` beside the entry stores each file's SHA-256 and size. Commit it. A changed file stops the command.
- `kinetograph fetch-deps <entry> --update` downloads everything again and accepts new bytes.

### Scripts, modules and WebGPU

- `<script type="importmap">` is read. Each `<script type="module">` is bundled with its imports and runs after the classic scripts.
- A remote module and its imports are downloaded ahead of time. Top-level `await` works, but the runtime doesn't wait for it.
- A page that draws with WebGPU, such as the `shaders.iife.js` blocks, is drawn natively. This includes render and compute passes, storage textures and `copyExternalImageToTexture`.
- WebGPU features that aren't drawn are reported on every frame. See [Known issues](/docs/known-issues/#webgpu).
- Three.js is reported on every frame, and `--strict` fails. See [Known issues](/docs/known-issues/#hyperframes-projects).

## Libraries

Third-party libraries run unchanged on the engine's DOM, as long as each frame follows a seek or the frame number. These were checked against Chrome.

- **d3**: d3 makes the paths and React draws them, or `d3-selection` appends to a ref.
- **rough.js**: the SVG and Canvas 2D generators.
- **Paper.js**: `paper-full` on a canvas.
- **Matter.js** and **Rapier**: step the world from the frame number.
- **Chart.js**: line charts on a canvas. Load a font before the chart.
- **Recharts**: SVG charts with `isAnimationActive={false}` and a fixed `width` and `height`.
- **visx**: shapes, scales and axes.
- **anime.js** v4: build a paused timeline and `seek(ms)` it to the frame.
- **Motion**: vanilla `animate()` with `controls.time = seconds` on a paused animation, and `motion.div` with style values.

The Web Animations API works on the frame's clock: `element.animate()`, `Animation`, `getAnimations()` and `document.timeline`, with the spec's timing, easing and composite modes. An animation starts at the frame it is played on, so a frame alone equals the frame in sequence.

### Libraries that run their own frame loop

`requestAnimationFrame` callbacks run once per frame with the frame's time, after the frame has rendered. Web Animations update just before them.

A jump to a frame (a still, or a worker starting at frame 600) runs both through the skipped frames without rendering them. So a still shows the same pixels as a full render, even for a library that advances by the time between frames.

Two limits:

- Motion clamps each step to 40 ms, so below 25 fps its animations run a little slow.
- A scene that starts over keeps the callbacks already asked for. Cancel your own `requestAnimationFrame` in the effect's cleanup.

## Layout of HTML content

CSS lays out HTML the way a browser would. A few rules are worth knowing:

- A group of HTML elements is laid out as a box the size of the composition, as Remotion's root `div` is.
- An `<AbsoluteFill>` or `<Sequence>` around HTML is an absolutely positioned column flex `div`.
- HTML inside a Kinetograph layer is laid out in the composition's box, not the layer's.
- A Kinetograph element inside HTML takes the size of its own box. A layer with no box, such as a group without `layout`, is 0 × 0.
- Styles are read on every frame, so animation comes from your component re-rendering. CSS `@keyframes` follow the frame's time.
