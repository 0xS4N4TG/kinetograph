title: Compositions and props
description: Declare the videos a project can render with registerRoot and Composition, and give them props.
---

A composition is one video: an id, a size, a frame rate, a length and the component that draws each frame. You list them in the entry file, inside `registerRoot`.

```tsx title="src/index.tsx"
import { Composition, Still, registerRoot } from '@kinetographdev/core';
import { Card } from './scenes/Card';

registerRoot(() => (
  <>
    <Composition
      id="Card"
      component={Card}
      durationInFrames={60}
      fps={30}
      width={640}
      height={360}
      defaultProps={{ title: 'Hello' }}
    />
    <Still id="Cover" component={Card} width={1280} height={720} />
  </>
));
```

The entry must call `registerRoot`. A file that only exports a component is not an entry, and the command stops and says so. The root runs once to find the compositions and draws nothing, so it can compute its list. Two compositions with the same id are an error.

## Composition props

| Prop | Meaning |
|---|---|
| `id` | The name that `--comp` picks. Without `--comp`, the first composition is used. |
| `component` | The component that draws a frame. |
| `durationInFrames`, `fps`, `width`, `height` | The length, frame rate and size. |
| `defaultProps` | The props the component gets when `--props` does not set them. |
| `schema` | A zod 4 schema. [Studio](/docs/studio/#props-and-presets) draws a form from it. Props are not checked against it in a render. |
| `background` | The background colour of every frame. The default is transparent. Use it in place of a full-size rectangle at the bottom, because it also fills the margin that effects read past the edge. |
| `margin` | The least margin in pixels around the canvas, for effects that draw past its edge. |

`Still` declares a one-frame composition, so it takes no length or frame rate. `Folder` wraps compositions and changes nothing in a render.

## Props

Props are the values a composition receives, such as a title. Set them from the command line with a JSON object or the path of a JSON file:

```sh
npx kinetograph render src/index.tsx --comp Card --props '{"title":"Goodbye"}'
```

The component gets `defaultProps` with the `--props` values merged over them. `getInputProps()` returns the `--props` object. Props saved as a preset in Studio are a JSON file in `presets/`, and `--props` renders it too.

## Look at your compositions

```sh
npx kinetograph compositions src/index.tsx
```

This lists each composition's id, size, frame rate and length. To draw a frame of one, see [Rendering](/docs/rendering/).

## HTML pages

A page declares its composition on the root element: `data-composition-id`, `data-width`, `data-height` and `data-duration` in seconds, at 30 fps. Without them the page renders at 1920 by 1080 for 1 second, and the commands warn. Props reach a mounted composition through `data-variable-values`, and its script reads them with `window.__hyperframes.getVariables()`. See [HyperFrames projects](/docs/compat/#hyperframes-projects).

## What works

- Drawn natively: compositions, `Still`, `Folder`, `defaultProps`, `--props`, `background` and `margin`.
- Approximated: `schema` draws a Studio form, but a render does not check props against it.
- Not supported: Remotion's `Config.*` calls do nothing, and say so once, because there is no `remotion.config.ts`.
- See [What works](/docs/compat/).
