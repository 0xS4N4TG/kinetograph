---
title: Effects
description: Blur, glow, shadows, colour grading and texture on any layer, with the effects prop.
---

Pass `effects={[...]}` to any layer. The effects run in order on the layer's own pixels, before it is clipped and blended.

```tsx title="src/Glow.tsx"
import { Rect, blur, dropShadow, glow, linearGradient } from '@kinetographdev/core';

export const Glow = () => (
  <Rect
    x={200}
    y={120}
    width={400}
    height={240}
    radius={32}
    fill={linearGradient(['#f9a8d4', '#fcd34d'], { angle: 160 })}
    effects={[glow(16), dropShadow({ y: 12, blur: 24, color: '#00000060' })]}
  />
);
```

An effect helper takes the effect's fields. Effects with one main number also take it bare, as `blur(24)`. `npx kinetograph effects` lists every effect with its fields and defaults.

## The effects

- **Blur and light:** `blur`, `backdropBlur`, `glow`, `chromaticAberration`.
- **Shadows:** `dropShadow`, `insetShadow`.
- **Colour:** `saturate`, `contrast`, `brightness`, `grayscale`, `sepia`, `invert`, `hueRotate`, `gradientMap`, `lut` and `colorGrade`.
- **Texture:** `grain`, `dither`, `halftone`, `dotMatrix` and `displace`.
- **Shape:** `cornerPin` pins a layer's four corners to four points.
- **Your own:** `shader({ code, uniforms })` runs a WGSL shader on the layer.

`motionBlur({ samples })` can sit in the same array. See [Motion blur](/docs/making-videos/motion-blur/).

## Gradients

`linearGradient`, `radialGradient` and `conicGradient` work as a shape's `fill` and as a text colour. A bare colour list spreads the stops evenly, and `[offset, colour]` pairs place them.

## Order

A layer's pixels go through its `effects`, then its `clip`, `mask` and `matte`, then `opacity` and `blendMode`. So a blur is cut off by the clip, and the clip is not blurred.

## Room past the edge

An effect such as a shadow or a glow draws past the layer's box. When its reach changes between frames, the engine rebuilds some buffers. Set `margin` on the composition to the largest reach, and nothing is cut off. See [Compositions](/docs/making-videos/compositions/).

## Remotion's effects

`@remotion/effects` has its own set of shader effects, such as `vignette()` and `lightLeak()`. They run from the copy in your project. See [Remotion effects](/docs/making-videos/remotion-effects/).

## What works

- Drawn natively: every effect above, as GPU passes.
- Approximated: `filter: blur()` and `backdrop-filter` past 532 px are drawn 532 px wide, as in Chrome. `backdrop-filter: blur()` reads only the backdrop inside the element's border box.
- Not supported: a WGSL `shader()` sees only its own layer, runs one pass, has no other texture and takes `f32` uniforms only.
- `doctor` lists the properties and elements that cannot be drawn. See [What works](/docs/compat/#canvas-2d-effects-and-shaders).
