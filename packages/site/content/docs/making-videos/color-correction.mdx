---
title: Color correction
description: Grade a picture or clip with colorCorrection(), levels(), curves() and lut(), or with the engine's own colorGrade and lut effects.
---

Pass `colorCorrection()`, `levels()`, `curves()` or `lut()` from `@remotion/effects` in the `effects` array of a picture or clip. The engine draws them on the GPU.

```tsx title="src/Graded.tsx"
import { Img, staticFile } from '@kinetographdev/core';
import { colorCorrection } from '@remotion/effects/color-correction';

export const Graded = () => (
  <Img
    src={staticFile('images/photo.jpg')}
    style={{ width: 1280 }}
    effects={[colorCorrection({ exposure: 0.3, contrast: 1.2, saturation: 1.3, temperature: 0.2 })]}
  />
);
```

`@remotion/effects` is Remotion's package, and Kinetograph runs the copy in your project. Install it at the same version as `remotion`. See [Remotion effects](/docs/making-videos/remotion-effects/) for how it runs and which components take `effects`.

## colorCorrection

`colorCorrection()` is the all-in-one adjustment. The example above sets `exposure`, `contrast`, `saturation` and `temperature`. Your installed version of `@remotion/effects` defines the rest of its parameters and their defaults.

## levels

`levels()` sets the black point, the white point and the gamma of the picture:

```tsx title="src/Levels.tsx"
import { levels } from '@remotion/effects/levels';

export const flat = [levels({ blackPoint: 0.1, whitePoint: 0.9, gamma: 1.4 })];
```

Pass the array as `effects` to an `Img`, `Video` or other component.

## curves

`curves()` bends the tone with points from `[0, 0]` to `[1, 1]`. Here the middle is pulled down:

```tsx title="src/Curves.tsx"
import { curves } from '@remotion/effects/curves';

export const moody = [curves({ points: [[0, 0], [0.5, 0.3], [1, 1]] })];
```

## lut

`lut()` grades through a 3D lookup table. Put the `.cube` file in `public/` and pass its text as `content`:

```tsx title="src/Look.tsx"
import { readFileSync } from 'node:fs';
import { Img, staticFile } from '@kinetographdev/core';
import { lut } from '@remotion/effects/lut';

const look = readFileSync(staticFile('luts/warm.cube'), 'utf8');

export const Look = () => <Img src={staticFile('images/photo.jpg')} style={{ width: 1280 }} effects={[lut({ content: look })]} />;
```

Read the file once, at the top of the module.

## Combine adjustments

Effects run in the order of the array, so the order changes the picture. Correct the colour first, then apply the look:

```tsx title="src/Combined.tsx"
const effects = [colorCorrection({ exposure: 0.2, temperature: 0.1 }), lut({ content: look })];
```

Put `colorCorrection()` before `lut()`, so the look is applied to the corrected colour and not the other way round.

## The engine's own grade

Kinetograph also has two native effects that work on any layer, with no extra package:

```tsx title="src/Native.tsx"
import { Image, colorGrade, lut, staticFile } from '@kinetographdev/core';

export const Native = () => (
  <Image
    src={staticFile('images/photo.jpg')}
    width={1280}
    height={720}
    effects={[
      colorGrade({ adjust: { exposure: 0.2, contrast: 0.1 }, curves: { master: [[0, 0], [0.5, 0.4], [1, 1]] } }),
      lut({ src: staticFile('luts/warm.cube'), amount: 0.8 }),
    ]}
  />
);
```

- `lut({ src, amount, interpolation })` reads a `.cube` file with a `LUT_3D_SIZE` from 2 to 64. `amount` (0 to 1, animatable) cross-fades from the original, and `interpolation` is `trilinear` (default) or `tetrahedral`. A 1D table is an error.
- `colorGrade` takes `adjust` (`exposure`, `contrast`, `highlights`, `shadows`, `whites`, `blacks`, `temperature`, `tint`, `vibrance`, `saturation`), colour `wheels`, `curves`, `hueCurves`, `secondaries`, a `lut`, a `vignette` and `grain`. It is HyperFrames' grade, and its numbers are plain, not keyframes.
- `gradientMap` colours a layer by brightness, as in a thermal camera.

## Studio

Studio has no sliders, histogram, curve editor or LUT drop for these yet. Set them in code, or ask the agent.

```txt title="Suggested prompt"
/kinetograph-markup Grade the photo warmer with a little more contrast, then apply luts/warm.cube at 80%. Show frame 0 before and after.
```

## What works

- Drawn natively: `colorCorrection`, `levels`, `curves` and `lut` from `@remotion/effects` (all supported, measured against Remotion in Chrome), and the engine's `lut`, `colorGrade` and `gradientMap`.
- HyperFrames: `data-color-grading` on `<video>`, `<img>` and `<canvas>` runs the whole HyperFrames grade as one GPU pass, with `adjust`, `wheels`, `curves`, `hueCurves`, `secondaries`, `.cube` luts and the 18 `effects`. A missing `.cube` drops the `lut` and says so.
- Approximated: a video with no named colour space is read with a different matrix from Chrome's.
- Not supported: grading in Studio, as above.
- See [What works](/docs/compat/#hyperframes-projects) and [Remotion effects](/docs/making-videos/remotion-effects/).
