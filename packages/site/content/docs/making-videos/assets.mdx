Put the files in the `public/` folder and name them with `staticFile()`. A render reads local files only, so a remote URL is an error: download the file into the project first.

```txt
my-video
├─ public
│  ├─ images
│  │  └─ logo.png
│  ├─ fonts
│  ├─ audio
│  └─ video
└─ src
   └─ index.tsx
```

```tsx title="src/Logo.tsx"
import { AbsoluteFill, Img, staticFile } from '@kinetographdev/core';

export const Logo = () => (
  <AbsoluteFill>
    <Img src={staticFile('images/logo.png')} style={{ width: 400 }} />
  </AbsoluteFill>
);
```

`staticFile('images/logo.png')` is the absolute path of `public/images/logo.png`. `public/` is the one next to the entry file, else the one next to the nearest `package.json`. With the layout `init` makes, that is the project's `public/`. See [Project structure](/docs/getting-started/project-structure/).

## Images

`Img` takes PNG, JPEG, GIF, WebP and SVG files. Its `style.width`, `style.height` and `style.objectFit` set the size. The native `Image` takes `width`, `height` and `fit` directly:

```tsx title="src/Photo.tsx"
import { Image, staticFile } from '@kinetographdev/core';

export const Photo = () => <Image src={staticFile('images/photo.jpg')} width={640} height={360} fit="cover" />;
```

An SVG file is drawn sharp at its drawn size. Text inside an SVG file used as a picture is not drawn, and the render warns.

## Image sequences

Every frame is drawn on its own, so a numbered sequence is a path built from the frame number:

```tsx title="src/Flipbook.tsx"
import { Img, staticFile, useCurrentFrame } from '@kinetographdev/core';

export const Flipbook = () => {
  const frame = useCurrentFrame();
  const name = String(frame + 1).padStart(4, '0');
  return <Img src={staticFile(`images/flip/${name}.png`)} />;
};
```

A file the project names and that is missing shows up in `lint` as a missing asset.

An animated GIF plays with `Gif`, which follows the composition's frame clock:

```tsx title="src/Loop.tsx"
import { Gif, staticFile } from '@kinetographdev/core';

export const Loop = () => <Gif src={staticFile('images/loop.gif')} width={320} height={320} />;
```

To write a sequence of images instead of a video, use `render --sequence`. See [Rendering](/docs/rendering/#image-sequences).

## Videos

`Video` and `OffthreadVideo` are the same component. The engine decodes the file, frame by frame, with no browser.

```tsx title="src/Clip.tsx"
import { OffthreadVideo, Sequence, staticFile } from '@kinetographdev/core';

export const Clip = () => (
  <Sequence from={30} durationInFrames={90}>
    <OffthreadVideo src={staticFile('video/clip.mp4')} width={1280} height={720} fit="cover" volume={0.8} />
  </Sequence>
);
```

The clip starts at the frame where its `Sequence` starts. It takes `trimBefore`, `trimAfter`, `playbackRate`, `loop`, `volume` and `muted`, and its sound goes into the mix. See [Audio](/docs/making-videos/audio/), and [Datamosh](/docs/making-videos/datamosh/) for the effect on `Video`.

## Audio

```tsx title="src/Music.tsx"
import { Audio, staticFile } from '@kinetographdev/core';

export const Music = () => <Audio src={staticFile('audio/music.mp3')} volume={0.5} />;
```

[Audio](/docs/making-videos/audio/) covers volume curves, trimming and synthesised sound.

## Fonts

Text only uses fonts you register. Put the font file in `public/fonts/` and register it with `loadFont`:

```tsx title="src/fonts.ts"
import { loadFont } from '@remotion/fonts';
import { staticFile } from '@kinetographdev/core';

loadFont({ family: 'Brand', url: staticFile('fonts/Brand-Medium.ttf') });
```

See [Fonts](/docs/making-videos/fonts/).

## CSS

A stylesheet you import, a `<style>` element, Tailwind and `*.module.css` files work. A file that CSS names, such as a `url()`, is looked for beside the entry file and then in `public/`:

```css title="src/index.css"
.card {
  background-image: url('/images/paper.png');
}
```

```tsx title="src/index.tsx"
import './index.css';
```

## Import statements

An `import` of a picture file gives its absolute path, which any `src` takes:

```tsx title="src/Poster.tsx"
import { Img } from '@kinetographdev/core';
import poster from './poster.png';

export const Poster = () => <Img src={poster} />;
```

This works for `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.avif` and `.svg`. Videos, audio and fonts are loaded with `staticFile()`.

## Caveats

- **No remote URLs.** `staticFile('https://...')` throws, and so does a remote `src` in a TSX project, because a frame is a pure function of the project. A HyperFrames page is different: Kinetograph downloads what it loads from the web once and pins it in `kinetograph.lock.json`. See [HyperFrames projects](/docs/compat/#hyperframes-projects).
- **Lists.** `getStaticFiles()` returns every file in `public/`, by name, without hidden files. `watchStaticFile()` does nothing, and `prefetch()` returns at once, because the files are already on disk.
- **A HyperFrames page** has no `public/` folder. It names files by a path from the page.

## What works

- Drawn natively: PNG, JPEG, GIF, WebP and SVG pictures, video, and sound files. Image imports and CSS `url()` of project files.
- Approximated or left out: text inside an SVG picture is not drawn. A remote file is read only from what `fetch-deps` downloaded and locked, and a video with no named colour space converts differently from Chrome.
- `doctor` lists what a project holds that the engine cannot draw. `lint` reports files the project names that are missing.

The full list is in [What works](/docs/compat/#video-and-audio).
