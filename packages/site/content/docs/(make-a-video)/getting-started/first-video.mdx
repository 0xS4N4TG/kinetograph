You will end with a short title card saved as an MP4. Ask your coding agent, or run three commands yourself. Both make the same kind of project.

<Video name="first-video" label="The finished title card: a word appears and a line grows under it" caption="The finished title card." silent />

## With your coding agent

Paste this into Claude Code, Codex or another coding agent:

```text title="Suggested prompt"
Set up Kinetograph (https://github.com/0xS4N4TG/kinetograph) for me by following its AGENTS.md: https://github.com/0xS4N4TG/kinetograph/blob/main/AGENTS.md Ask me first whether I want the prebuilt package (recommended) or a build from source, and ask before installing anything system-wide or installing the Kinetograph agent skills.
```

Choose the prebuilt package. When it finishes, ask for the video:

```text title="Suggested prompt"
Make a 5 second title card that says "Hello" and save it to out/title.mp4. Look at the frames before you save it.
```

Your agent writes the video and looks at it. It fixes what is off and saves the MP4.

## With three commands

In an empty folder:

```sh
npx kinetograph init
npm install
npx kinetograph render src/index.tsx
```

The video is `out/renders/Main.mp4`. Open it.

## Change something

Open `src/scenes/Title.tsx` and change the words "Hello, Kinetograph". Render again.

To see changes as you make them, open the preview and press Space to play:

```sh
npx kinetograph studio src/index.tsx
```

Press Ctrl-C to stop it.

## Good to know

- You need Node.js 22 or newer.
