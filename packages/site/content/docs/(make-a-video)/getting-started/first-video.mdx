Kinetograph turns one sentence into a video you can keep editing. Start with the coding agent you already use. If you prefer a terminal, three commands make the same kind of project.

<LinkCard title="Install Kinetograph" icon="download" href="/docs/getting-started/installation/">
  One command, about a minute. Your agent can run it for you.
</LinkCard>

## With your coding agent

For Claude Code, Codex, Cursor or any agent that works in a folder on your computer.

### The short way

Paste this into the agent. It installs Kinetograph, makes a title card and saves the MP4. You only change the words.

```text title="Suggested prompt"
Set up Kinetograph (https://github.com/0xS4N4TG/kinetograph) for me by following its AGENTS.md: https://github.com/0xS4N4TG/kinetograph/blob/main/AGENTS.md Choose the prebuilt package and ask before installing anything system-wide. Then make a 5 second title card that says "Hello" and save it to out/title.mp4. Look at the frames before you save it.
```

### Step by step

<Steps>
  <Step title="Install the skills">
    Step-by-step pages: [Claude Code](/docs/agents/claude-code/), [Codex](/docs/agents/codex/), [Cursor](/docs/agents/cursor/).

    In your project folder, run this and pick your agent. Then open or restart the agent there:

    ```sh
    npx skills add 0xS4N4TG/kinetograph
    ```
  </Step>
  <Step title="Ask for the video">
    ```text title="Suggested prompt"
    Make a 5 second title card that says "Hello" and save it to out/title.mp4. Look at the frames before you save it.
    ```

    Your agent writes the video and looks at it. It fixes what is off and saves the MP4.
  </Step>
  <Step title="Change it">
    Say what to change in the same conversation, or open the preview with a timeline:

    ```sh
    npx kinetograph studio src/index.tsx
    ```

    Press Space to play and Ctrl-C to stop. [Edit in Studio](/docs/studio/) walks through it.
  </Step>
</Steps>

## In the terminal

No agent needed. In an empty folder:

<Steps>
  <Step title="Make the project">
    ```sh
    npx kinetograph init
    npm install
    ```
  </Step>
  <Step title="Save the video">
    ```sh
    npx kinetograph render src/index.tsx
    ```

    The video is `out/renders/Main.mp4`. Open it.
  </Step>
  <Step title="Change something">
    Open `src/scenes/Title.tsx`, change the words "Hello, Kinetograph", and render again.
  </Step>
</Steps>

<Note>You need Node.js 22 or newer for either route.</Note>
