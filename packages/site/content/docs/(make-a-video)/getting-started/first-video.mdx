Kinetograph turns one sentence into a video you can keep editing. If you already work with a coding agent, install the skills and ask it. If you prefer a terminal, three commands make the same kind of project.

<LinkCard title="Install Kinetograph" icon="download" href="/docs/getting-started/installation/">
  One command, about a minute. Your agent can run it for you.
</LinkCard>

## With your agent

For Claude Code, Codex, Cursor or any agent that works in a folder on your computer.

### The short way

Install the skills once from a terminal in your project folder, then open or restart your coding agent there:

```sh
npx kinetograph skills update
```

Paste this into the agent. It makes the video and opens the preview. You only change the URL.

```text title="Install prompt"
Set this folder up for Kinetograph and make me a video.

1. If the Kinetograph skills are missing, stop and tell me: I install them with npx kinetograph skills update
2. Then, using /kinetograph, make a 10-second product intro for https://example.com
3. Open the local preview when it is done and tell me the project folder.
```

## In the terminal

No agent needed. In an empty folder:

<Steps>
  <Step title="Make the project">
    ```sh
    npx kinetograph init
    npm install
    ```
  </Step>
  <Step title="Save the video">
    ```sh
    npx kinetograph render src/index.tsx
    ```

    The video is `out/renders/Main.mp4`. Open it.
  </Step>
  <Step title="Change something">
    Open `src/scenes/Title.tsx`, change the words "Hello, Kinetograph", and render again.
  </Step>
</Steps>

<Note>You need Node.js 22 or newer for either route.</Note>
