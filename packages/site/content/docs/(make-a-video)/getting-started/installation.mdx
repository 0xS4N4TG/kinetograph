Installing takes about a minute. Ask your coding agent to do it, or run one command.

## With your coding agent

Paste this into Claude Code, Codex or another coding agent:

```text title="Suggested prompt"
Set up Kinetograph (https://github.com/0xS4N4TG/kinetograph) for me by following its AGENTS.md: https://github.com/0xS4N4TG/kinetograph/blob/main/AGENTS.md Ask me first whether I want the prebuilt package (recommended) or a build from source, and ask before installing anything system-wide or installing the Kinetograph agent skills.
```

The agent asks which install you want, installs it and checks it. It then offers to add [skills](/docs/agents/skills/), short guides that teach your agent Kinetograph.

## With one command

In your project folder:

```sh
npm install kinetograph
```

## Check it works

```sh
npx kinetograph doctor
```

It prints your system and whether the drawing engine loaded. If it says `NOT loaded`, the next line gives the reason. See [Troubleshooting](/docs/help/).

## Good to know

- Needs: Node.js 22 or newer.
- It runs on a Mac with Apple Silicon, on Linux (64-bit) and on Windows (64-bit).
- Nothing else to install. It needs no screen, so it also runs on a server.
- On any other system, [build from source](/docs/contributing/build-from-source/).
