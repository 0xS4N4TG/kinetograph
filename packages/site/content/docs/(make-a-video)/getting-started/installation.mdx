Installing takes about a minute. Ask your coding agent to do it, or run one command.

## With your coding agent

Paste this into Claude Code, Codex or another coding agent:

```text title="Suggested prompt"
Set up Kinetograph (https://github.com/0xS4N4TG/kinetograph) for me by following its AGENTS.md: https://github.com/0xS4N4TG/kinetograph/blob/main/AGENTS.md Ask me first whether I want the prebuilt package (recommended) or a build from source, and ask before installing anything system-wide or installing the Kinetograph agent skills.
```

The agent asks which install you want, installs it, checks it, and then asks whether to add the [agent skills](/docs/agents/skills/).

## With one command

In your project folder:

```sh
npm install kinetograph
```

## Check it works

```sh
npx kinetograph doctor
```

It prints the Node version, your system, and whether the drawing engine loaded. If it says `NOT loaded`, the line after it gives the reason. See [Troubleshooting](/docs/help/).

## Good to know

- Needs: Node.js 22 or newer, on a Mac with Apple Silicon, Linux (64-bit Intel or AMD) or Windows (64-bit).
- Nothing else to install. A window or screen is not needed, so it also runs on a server.
- Any other system, or working on Kinetograph itself: [build from source](/docs/contributing/build-from-source/).
