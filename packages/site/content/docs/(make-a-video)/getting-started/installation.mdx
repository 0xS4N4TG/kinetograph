There are two ways to install:

- **Prebuilt from npm (recommended).** About a minute, with no Rust, FFmpeg or compiler to set up.
- **From source.** Only to work on the engine, or on a platform with no prebuilt package (Intel Mac, Linux on ARM). It takes 15 to 30 minutes.

## With a coding agent

Paste this into Claude Code, Codex or another coding agent:

```text
Set up Kinetograph (https://github.com/0xS4N4TG/kinetograph) for me by following its AGENTS.md:
https://github.com/0xS4N4TG/kinetograph/blob/main/AGENTS.md
Ask me first whether I want the prebuilt package (recommended) or a build from source,
and ask before installing anything system-wide or installing the Kinetograph agent skills.
```

The agent asks which install you want, installs it, runs `doctor`, and then asks whether to add the [agent skills and the MCP server](/docs/agents/claude-code/).

## From npm

```sh
npm install kinetograph
```

You need Node.js 22 or newer. The native addon comes prebuilt for macOS (arm64), Linux (x64, glibc) and Windows (x64). It carries FFmpeg, so you install nothing else.

Kinetograph uses the GPU when there is one, and needs no window or display, so it runs on a server or in CI.

## From source

You need:

- Node.js 22 or newer.
- A stable Rust toolchain from rustup.
- The FFmpeg development libraries, pkg-config and libclang.

- macOS: `brew install ffmpeg pkgconf`
- Debian or Ubuntu: `sudo apt-get install libavcodec-dev libavformat-dev libswscale-dev libavutil-dev libclang-dev pkg-config`

Then, from the repository root:

```sh
npm ci
npm run build
```

## Check the install

```sh
npx kinetograph doctor
```

With no entry, `doctor` prints the Node version, the platform, whether the addon loaded and which renderer draws. If the addon line says `NOT loaded`, the text after it gives the reason.

## FFmpeg licence

The FFmpeg libraries linked into the native addon are LGPL 2.1 or later. The `bin/ffmpeg` program in the same npm package is a separate executable under GPL 2 or later, which the addon runs as a child process for `libx264` and `libx265`. The two share no memory or code. To use your own `ffmpeg`, set `KINETOGRAPH_FFMPEG`; to keep the GPL program out of your install, delete `bin/ffmpeg`. Sources and build scripts are in the repository.
