Kinetograph is a free, open-source video engine. You make the request; an agent builds an editable project; Kinetograph draws it and saves an MP4.

## What can it make?

Every tile below is a finished Kinetograph film. Open one to watch it with sound.

<FilmGrid />

## Three things to know

**Agent-built.** You describe the video; your agent writes the project and checks the frames. You do not need to write code for this path.

**Editable.** The result is a project folder of plain files. An agent, Studio and your own tools can work on the same files.

**Reliable render.** A frame depends only on its number, so rendering twice gives the same video.
