Install the skills, then ask Claude Code for a video. Claude Code writes the project in your folder, looks at the frames and saves the MP4 on your computer.

```sh
npx skills add 0xS4N4TG/kinetograph
claude mcp add kinetograph -- npx -y kinetograph mcp
```

## Before you start

- [Claude Code](https://code.claude.com/docs), signed in. Its usage bills to your Claude account.
- Node.js 22 or newer.

## Install

Paste this into Claude Code and let it do the setup:

```text title="Install prompt"
Set up Kinetograph (https://github.com/0xS4N4TG/kinetograph) for me by following its AGENTS.md: https://github.com/0xS4N4TG/kinetograph/blob/main/AGENTS.md. Use the prebuilt package and install the Kinetograph agent skills system-wide.
```

Or install by hand:

  <Tab value="Skills">

    ```sh
    npx skills add 0xS4N4TG/kinetograph
    ```

## Ask for your first video

Open Claude Code in an empty folder and paste:

```text title="Suggested prompt"
/kinetograph-markup Make a 5 second title card for my product, check it with strip and lint, and render it to out/title.mp4.
```

## What happens

1. Claude Code reads the skills, makes a project in your folder and writes the video.
2. It looks at the frames and checks the layout, then fixes what is off.
3. It saves the MP4.

Watch the first version and say what to change, in the same conversation.

## Preview and render

To reopen the preview with a timeline and a chat, run this in the project folder:

```sh
npx kinetograph studio src/index.tsx
```

The preview opens in Studio, where you can also edit the video by hand. To save the MP4 yourself:

```sh
npx kinetograph render src/index.tsx
```

You can also ask your agent to render it.

## If something goes wrong

- **Claude Code does not see the skills.** Start a new session. `npx kinetograph doctor` lists each installed skill.
- **A render fails.** Run `npx kinetograph doctor` and fix what it reports.
- **Anything else.** See [Troubleshooting](/docs/help/).
