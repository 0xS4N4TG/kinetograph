title: Make videos with Codex
description: Install the Kinetograph skills in Codex, ask for a video in plain words, then preview it and save the MP4 on your computer.
---

Install the skills, then ask Codex for a video. Codex writes the project in your folder, looks at the frames and saves the MP4 on your computer.

```sh
npx skills add 0xS4N4TG/kinetograph
codex mcp add kinetograph -- npx -y kinetograph mcp
```

## Before you start

- Codex, signed in.
- Node.js 22 or newer.

## Install

The first command asks which agents to install the skills for. Pick Codex. The second connects the [tools Kinetograph gives your agent](/docs/mcp/). `codex mcp list` shows the result.

You can write the same connection by hand in `~/.codex/config.toml`:

```toml title="~/.codex/config.toml"
[mcp_servers.kinetograph]
command = "npx"
args = ["-y", "kinetograph", "mcp"]
```

Start a new Codex session afterwards. [Agent skills](/docs/agents/skills/) lists what each skill does.

## Ask for your first video

Open Codex in an empty folder and paste:

```text title="Suggested prompt"
Make a 5 second title card for my product, check it with strip and lint, and render it to out/title.mp4.
```

Codex makes the project, looks at the frames, fixes what is off and saves the MP4. Say what to change in the same conversation.

## Preview and render

To reopen the preview with a timeline and a chat, run this in the project folder:

```sh
npx kinetograph studio src/index.tsx
```

The preview opens in Studio, where you can also edit the video by hand. To save the MP4 yourself:

```sh
npx kinetograph render src/index.tsx
```

You can also ask your agent to render it.

## If something goes wrong

- **Codex does not see the skills.** Start a new session. `npx kinetograph doctor` lists each installed skill.
- **Anything else.** See [Troubleshooting](/docs/help/).
