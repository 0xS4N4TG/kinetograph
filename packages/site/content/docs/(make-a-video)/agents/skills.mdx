A skill is a folder with a `SKILL.md` that teaches a coding agent one job. Install them once, and your agent knows how to make Kinetograph videos.

## Install for a person

Install them all with one command:

```sh
npx skills add 0xS4N4TG/kinetograph
```

The [`skills`](https://www.npmjs.com/package/skills) CLI asks which agents to install them for. `npx skills add 0xS4N4TG/kinetograph --list` shows what it found and installs nothing.

## Install or refresh from an agent

Paste this into your agent. It installs the skills for every project and checks them:

```text title="Install prompt"
Install the Kinetograph agent skills system-wide with npx skills add 0xS4N4TG/kinetograph. Install all of them. Then run npx kinetograph doctor and tell me if any skill is not current.
```

## What the skills cover

| Skill | For |
|---|---|
| `kinetograph` | The loop an agent follows: write, look, check, render. Start here. |
| `kinetograph-create` | Starting a new project. |
| `kinetograph-markup` | Writing the video: layers, text, animation, effects and sound. |
| `kinetograph-render` | Rendering and checking a project. |
| `kinetograph-studio` | Working in Studio. |
| `kinetograph-docs` | Looking things up in these docs. |
| `kinetograph-upgrade` | Updating Kinetograph and the skills. |
| `kinetograph-migrate` | Moving an existing Remotion project onto Kinetograph. See [Migrate from Remotion](/docs/migrating/remotion/). |
| `kinetograph-taste-clone` | Turning a reference reel into a spec or a reusable style. It comes from [kinetograph-ui](https://github.com/0xS4N4TG/kinetograph-ui). See the [Taste skill](/docs/agents/taste-clone/). |

## Using the skills

You don't need to call a skill by name. Ask for the video and the agent picks the one that fits. Prompts for each are in the tips:

- `kinetograph-markup`: [Motion and transitions](/docs/tips/motion/) and [Text, captions and code](/docs/tips/text-captions-code/).
- `kinetograph-studio`: [Editing an existing video](/docs/tips/editing/).
- `kinetograph-taste-clone`: [Recreating something you saw](/docs/tips/matching/) and the [Taste skill](/docs/agents/taste-clone/).
- `kinetograph-render`: [Rendering](/docs/rendering/).

More are in [Example prompts](/docs/tips/example-prompts/).

## Docs for agents

`kinetograph-docs` lets an agent look up these docs. Every page is also served as Markdown at `https://kinetograph.dev/llms.mdx/<path>.md`, so `/docs/reference/cli/` is `llms.mdx/reference/cli.md`. `https://kinetograph.dev/llms.txt` is a short summary for agents. The page's **Copy page** menu offers the same file.

## The loop the skill teaches

1. **Write** a project file that calls `registerRoot`.
2. **Look.** `strip` shows twelve labelled frames at once, `still` shows one, and `onion` shows a motion path.
3. **Check** without looking at pixels. `inspect` gives each layer's position and bounds, `lint` reports overflow and missing fonts and assets, and `check` catches type errors.
4. **Fix** and go back to step 2.
5. **Render** with `render`. Use `--draft` for a half-size look first, and run `doctor` before a long render to see what it will leave out.

A prompt as short as "make a 5 second title card for X, check it with strip and lint, and render it to out/title.mp4" is enough to start this loop. Kinetograph needs no account, login or API key.

## Keep them current

Every Kinetograph command checks once a day whether the CLI or an installed skill is out of date, and prints one line. It never installs anything. To update:

```sh
npm install kinetograph@latest
npx skills add 0xS4N4TG/kinetograph
```

See [Update Kinetograph](/docs/upgrading/) for plugins, versions and the check afterwards.

The skills live in the GitHub repo, in [`packages/cli/skills/`](https://github.com/0xS4N4TG/kinetograph/tree/main/packages/cli/skills).

## If the agent cannot see a skill

Start a new session in your agent, because skills load at the start. Then run `npx kinetograph doctor`. It lists each installed skill with its version and whether it is current.
