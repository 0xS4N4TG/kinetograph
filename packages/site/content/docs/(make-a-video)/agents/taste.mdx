---
title: Match a reference
description: An agent skill that turns a reference video into a measured spec, or into a reusable style for new videos.
---

`kinetograph-taste-clone` gives an agent a reel or reference video. It downloads the video, reads every frame and writes a spec of numbers: timing, layout, colour, type, shadows and transitions. It builds from the spec and checks each shot against the reference, side by side, before it shows you anything.

It works with Kinetograph, Remotion or any frame-based renderer. It needs `ffmpeg`, `python3` and, for URLs, `yt-dlp`.

## Install

The skill comes from [kinetograph-ui](https://github.com/0xS4N4TG/kinetograph-ui) (MIT):

```sh
npx skills add 0xS4N4TG/kinetograph-ui
```

## Try it

```text
Here is a reel: <url>. Match it with our own words and objects.
Then save its taste so we can make more videos like it.
```

The agent writes `SPEC.md` with a number for every timing and layout value, builds each shot from it, and fixes any shot that fails the comparison before you see it. Then you ask for new videos in the saved taste (`TASTE.md` and `taste.json`).

## Two modes

- **Match.** Your words, objects and brand, with the reference's timing, camera, layout, type, light and transitions. The reference's own text, logos and people are swapped out.
- **Taste.** Only the style is kept: palette, type, how text writes on, light and shadows, entrances, transitions and rhythm. Content and exact frame numbers are left out. A taste written from a match that passed its checks is measured; one written from watching alone is a guess.

Downloaded media stays in a git-ignored folder and is never committed.

Other skills are in [Use with agents](/docs/agents/).
