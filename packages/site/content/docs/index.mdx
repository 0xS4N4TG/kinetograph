---
title: Overview
description: What Kinetograph is.
---

Kinetograph is a programmatic video engine with no browser in it. You write video in TypeScript with Remotion's API, and a Rust GPU compositor renders every frame natively.

Agents write the scene, Node runs it, and the renderer draws CSS, SVG, Canvas 2D, WebGL shaders and 3D without Chrome.

To have a coding agent make videos, see [Use with agents](/docs/guides/agents): the MCP server and the agent skill.
