---
title: Overview
description: What Kinetograph is.
---

Kinetograph makes videos from code, without a browser. You write the video in TypeScript with Remotion's API, or as an HTML page. A Rust program on the GPU draws every frame.

It draws CSS, SVG, Canvas 2D, WebGL shaders and 3D itself, with no Chrome. Coding agents can write the scenes too.

Where to go next:

- New here: [Installation](/docs/getting-started/installation/), then [First video](/docs/getting-started/first-video/).
- You have a Remotion project: see [What works](/docs/compat/) for what is drawn, what is approximated and what isn't.
- You have a [HyperFrames](https://github.com/heygen-com/hyperframes) project: it renders as it is, GSAP timelines included. See [HyperFrames projects](/docs/compat/#hyperframes-projects).
- You want to edit with a preview, a timeline and a chat with your coding agent: [Studio](/docs/guides/studio/).
- You want an agent to make videos: [Use with agents](/docs/guides/agents/) covers the MCP server and the agent skill.
