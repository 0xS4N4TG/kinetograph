title: Overview
description: What Kinetograph is, and where to start.
---

Kinetograph makes videos from code, without a browser. You write the video in TypeScript with Remotion's API, or as an HTML page, and a Rust program on the GPU draws every frame. It draws CSS, SVG, Canvas 2D, WebGL shaders and 3D itself, with no Chrome.

```sh
npx kinetograph init
npm install
npx kinetograph render src/index.tsx
```
