---
title: Overview
description: What Kinetograph is.
---

Kinetograph makes videos from code, without a browser. You write the video in TypeScript using Remotion's API, or as an HTML page, and a Rust program on the GPU draws every frame.

It draws CSS, SVG, Canvas 2D, WebGL shaders and 3D itself, with no Chrome. Coding agents can write the scenes too.

If you already have a Remotion project, see [Remotion compatibility](/docs/compat/) for what works and [Known issues](/docs/known-issues/) for what doesn't. A [HyperFrames](https://github.com/heygen-com/hyperframes) project renders as it is, GSAP timelines and all: see [HyperFrames projects](/docs/compat/#hyperframes-projects).

To have a coding agent make videos, see [Use with agents](/docs/guides/agents): the MCP server and the agent skill.
