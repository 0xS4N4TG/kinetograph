# Contributing

Issues and pull requests are welcome. Read
[Contributing to Kinetograph](https://kinetograph.dev/docs/contributing/) before you start: it covers how to report a
problem, set up a clone, run the tests and send a pull request. The same page is in this repository at
[packages/site/content/docs/contributing.mdx](packages/site/content/docs/contributing.mdx).

Kinetograph is a commercial project. By sending a pull request, you agree that your changes can be used, changed and
licensed as part of Kinetograph, including under its commercial licences. See [LICENSE.md](LICENSE.md) and
[COMMERCIAL.md](COMMERCIAL.md).
