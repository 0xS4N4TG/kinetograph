# Khronos sample models

Three models of the [glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets), used by the glTF animation,
morph target and skin tests (`crates/core/src/scene3d/model.rs`, `crates/core/tests/scene3d.rs`). The files of each model
are licensed under Creative Commons Zero v1.0 Universal (CC0-1.0), per each model's `LICENSE.md` in that repository:

- `AnimatedMorphCube.glb` (Animated Morph Cube): two morph targets, animated weights.
- `InterpolationTest.glb` (Interpolation Test): translation, rotation and scale clips with `LINEAR`, `STEP` and `CUBICSPLINE`.
- `SimpleSkin.gltf` (Simple Skin): two joints, a rotation clip.
